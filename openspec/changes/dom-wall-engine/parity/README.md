# Task 4.2 — Component-level parity captures

Automated Playwright captures of the **real production build** of the DOM wall
against the pinned `?demo=4` fixture, for the three test viewports and the three
circadian moods.

## What is captured

| Dimension | Values |
| :--- | :--- |
| Viewport | `1600×1000`, `1920×1080`, `390×844` (deviceScaleFactor 1) |
| Mood (pin) | `?mood=concrete`, `?mood=alabaster`, `?mood=chiaroscuro` |
| State | Row-0 Overview (entry), Album Focus (click a placard), Print Focus (click a print) |
| Extras | Brushed Aluminum placard variant (`1600×1000` + `390×844`, concrete), macro tier (`?demo=1000` zoomed out) |

Fixture: `/?demo=4` — 4 albums × 12–16 prints, mixed `4:5` / `3:2` / `2:3`, real
JPEGs from `public/demo/` (generated by `../fixtures/generate-demo-photos.mjs`).

File naming: `<viewport>-<mood>-<state>.png`
(e.g. `1600x1000-concrete-print.png`), plus
`1600x1000-concrete-brushed-aluminum.png`, `390x844-concrete-brushed-aluminum.png`
and `1600x1000-chiaroscuro-demo1000-macro.png`.

`parity-results.json` records, per page: tier, island/print/mosaic/placard counts,
print-focus dimming, HUD segments, dock items, focus bar text, horizontal overflow,
row-0 framing (aspect-aware target vs fully-framed count), DOM mood, console
errors and any HTTP ≥ 400.

## Reproduce

```bash
# 1. Production build + server (same env pattern as the runtime probe)
DATABASE_URL='file::memory:' \
ADMIN_PASSWORD='test-password-1234' \
AUTH_SECRET='test-secret-that-is-long-enough-for-hs256-signing' \
STORAGE_DRIVER=local LOCAL_UPLOAD_DIR='./data/test-uploads' \
  npm run build

DATABASE_URL='file::memory:' \
ADMIN_PASSWORD='test-password-1234' \
AUTH_SECRET='test-secret-that-is-long-enough-for-hs256-signing' \
STORAGE_DRIVER=local LOCAL_UPLOAD_DIR='./data/test-uploads' \
  npx next start -p 3111

# 2. Capture (Playwright is not a project dependency)
PLAYWRIGHT_MODULE=/path/to/node_modules/playwright-core/index.js \
  node openspec/changes/dom-wall-engine/parity/capture-parity.mjs
```

`PARITY_ORIGIN` overrides the base URL (default `http://127.0.0.1:3111`).

## Headless caveats

- Rendering is Chromium + SwiftShader (software WebGL2). Colour, layout,
  `backdrop-filter`, shadows and typography are representative; GPU-specific
  rasterisation (font gamma, sub-pixel AA) is not.
- The YouTube thumbnail proxy needs network. Offline it answers `502` and the
  plaque falls back to its charcoal facade with the play glyph — that fallback is
  the shipped behaviour, not a broken image.
